# Use Triage Lanes for Recall-Biased Review

The Code Review Agent should search broadly for plausible failure modes, then use Triage Lanes to keep final output disciplined. Proven concerns that pass the Finding Gate become Findings, confidence-blocking ambiguity becomes Open Questions, and important unproven concerns become a short Residual Risks section. This preserves recall during analysis without turning low-confidence speculation into merge-blocking review comments.
